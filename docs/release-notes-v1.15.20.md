> **本版与 v1.15.19 内容完全相同**,没有代码改动。
>
> 目的:插件「检查更新」按「最新 Release = 测试版、前一个 Release = 稳定版」取版本。

> 点「更新稳定版」的用户会下载到有问题的版本;因此用一个内容相同的 v1.15.20 占住测试版位,
> 让**稳定版位变成已修复的 v1.15.19**。
>
> - 已在 1.15.19 的用户**不需要升级**;
> - 走「更新稳定版」通道的用户会拿到 v1.15.19(已修复)。
