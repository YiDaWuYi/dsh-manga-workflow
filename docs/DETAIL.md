# 漫画汉化工作流

把「标框 → OCR → 翻译 → 擦字 → 嵌字 → 校对」接进 DSH:Agent 可以调工具,人可以在侧边栏「漫画工作台」里点按钮,
也可以用桌面标框工具。**插件代码全部由 AI 生成与编写**(DeepSeek Harness Agent),作者 YiDaWuYi。

## 提供的工具

| 工具 | 作用 |
|---|---|
| `manga_ocr` | 对已标框的漫画跑本地 OCR(日文 Manga OCR / 韩英 EasyOCR),写 `ocr_text.json` |
| `manga_embed` | 按 `trans.json` 擦原文 + 写中文,可选 GPU LaMa 去字或预览 |
| `manga_status` | 汇总页数、框数、已译数、整页未译的页 |
| `manga_failures` | 读失败报告:OCR 空 / 兜底失败 / 疑似识别错 / 缺译文,带归类与处理建议 |
| `manga_dsh_translate` | 经本机 DSH 桥用 DSH 模型翻译(无需 API Key),可只翻某一页 |
| `manga_report` | 读网页面板排队的嵌字报告(读后标记已消费) |
| `manga_bench` | 以已有 `regions.json` 为准,测自动标框的召回/精确/噪声率(需 GPU) |

## 侧边栏:漫画工作台

| 区域 | 能力 |
|---|---|
| 启动页 | 路径输入 / 浏览选目录 / 引擎检测 / 视觉引擎状态 |
| 流程按钮 | **自动标框 / OCR / 翻译 / 校对 / 嵌字 / 确认嵌字 / 失败报告**,均支持 **范围:此页 / 整本** |
| 画布 | 框选 / 自由框选;类型(正文·拟声·标题)、原文处理(译文直盖/抹除/色块覆盖)、按框 GPU、竖横、字号与自动字号;单击回填参数并实时写回;右键删框、双击改字、撤销;**显示译文 / 显示原文** 两个勾选(默认关,便于对照核对) |
| 对照工具 | **强制重译**(覆盖已有译文重翻)、失败报告(四类归类)、版本标签(V1.16) |
| 其它 | 页码直达、保存(Ctrl+S)、样式库(正文/拟声/标题)、日志与底部状态条 |

双端都不支持:画面缩放、同步(配对)。任务中断双端都支持(工具栏「取消当前任务」,杀进程树)。

## 主要变化(1.15.21 → 1.16.0)

- **失败报告**:并行统计 OCR 空 / 兜底失败 / 疑似识别错 / 缺译文,给四类归类与建议;面板、DSH 工具、注入的会话建议同口径。
- **判型修正**:按 OCR 文本二次判型(台词↔拟声),减少「台词被直盖导致双语叠字」。
- **参数写回**:网页点框回填 + 改参数实时写回;桌面「自动字号」实时写回。
- **翻译可控**:双端「强制重译」;已全译时不再空跑,直接提示。
- **失败兜底**:OCR 空结果不再假装成功;首次加载模型会提示「正在加载,30–60 秒属正常」。
- **噪音框**:页码/UI/碎框自动跳过翻译与嵌字。
- **形状/样式**:短气泡允许缩到 10 号;#5 多层描边与投影采样(实验开关,默认关)。

## 数据位置

- 项目数据:`<工作区>/projects/<书名>/`(regions / trans / ocr_text / config / 失败报告)
- 成品输出:`<工作区>/已完成/<书名>/`
- 源书目录**只读**;脚本通过 `MANGA_DATA_DIR` 指向项目数据。

## 安装

1. DSH →「插件市场」搜索 **漫画汉化** 或 **dsh-manga-workflow** → 安装;
2. 或下载安装包 `dsh-manga-workflow-<ver>.tgz`:https://github.com/YiDaWuYi/dsh-manga-workflow/releases

## 已知边界

- 装饰字 / 艺术字 / 目录页 OCR 不可靠,建议手填原文;
- 拟声默认「直盖」不擦除,会有轻微双语叠字(可改抹除,抹除也可能留痕);
- 去码只能模糊填补,不能高清重绘;
- 排版是规则化渲染,观感不如专业嵌字;这些是「低成本 + 本地跑」路线的取舍。
