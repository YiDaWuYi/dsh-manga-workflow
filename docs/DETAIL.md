# 漫画汉化工作流

把本地标框、OCR、去字、嵌字这套流程接进 DSH,让 Agent 直接调用;并在侧边栏提供一个**漫画工作台**面板(含设置页 / 帮助页),在对话输入框下方的状态栏显示一条可开关的启动提示。

## 提供的工具

| 工具 | 作用 |
|---|---|
| `manga_ocr` | 对已标框的漫画文件夹跑本地 OCR(日文 Manga OCR / 韩文 / 英文 EasyOCR),生成 `ocr_text.json` |
| `manga_embed` | 按 `trans.json` 擦原文 + 写中文;可选 GPU LaMa 去字或预览模式 |
| `manga_status` | 汇总文件夹:有标框页数、总框数、已翻译数、整页未翻译的页 |
| `manga_bench` | **基准测试**:把已有的 `regions.json` 当标准答案,对比自动标框的召回率 / 精确率 / 噪声率 |

## 侧边栏:漫画工作台

插件启用后,左侧边栏会出现 **🎨 漫画工作台** 入口,点开后是一个工作台面板:

| 启动页 | 路径输入 +「浏览…」系统对话框、引擎检测(8 项)、视觉引擎状态、页脚声明 |
| 文件夹输入 | 粘贴路径 / 浏览选目录 / 记住上次路径(可关) |
| 状态 | 显示页数、框数、已翻译数 |
| 流程按钮 | **OCR / 翻译 / 校对 / 嵌字**,异步任务 + 日志轮询,不阻塞界面 |
| 页码导航 | ◀ / ▶ 翻页,右侧「保存」写回 `regions.json`(Ctrl+S) |
| **网页标框** | 框选 / 涂抹;竖排横排、字号、拟声词、抹除原文、黑/白字、外框;撤销(最多 40 步);右键删框、双击改字 |
| 设置 / 帮助 | 顶部按钮,或从启动页进入 |
| 日志 | 脚本运行输出(轮询任务进度) |

> 网页版仍缺:自动标框、一键识别、重标同步、画面缩放。这些用桌面版 `mark.bat`;
> 启动页可一键「启动桌面版」并自动带上当前文件夹。

**长任务处理**:网页端 `/run` 立即返回 `jobId`,前端轮询 `/job` 拿日志(不阻塞);
桌面端用后台线程 + `Popen` 流式读 stdout 刷到状态栏,顶栏「取消当前任务」用
`taskkill /T /F` 结束进程树,关窗时也会自动终止子进程。

## 设置页

| 区块 | 内容 | 落盘位置 |
|---|---|---|
| 视觉模型 / API | 模型名、API Base、API Key;4 个厂商预设;清空 Key | `~/.modlens/config.json` 的 `providers.openai` |
| 测试连接 | 发一条最小**文本**请求,验证地址 / Key / 模型名 | — |
| 测试识图 | 真发一张**绿色三角形**图,验证模型是否具备视觉能力 | — |
| 界面选项 | DSH 侧边栏开关(双端共享)、启动提示弹窗开关(共享)、记忆上次路径(两端独立) | `~/.manga-workflow/settings.json` |

## 帮助页

启动页 / 工作台顶部「帮助」打开内置说明:基本流程、鼠标与快捷键、网页版 vs 桌面版对照表(18 项)、
设置页说明、视觉引擎与免费模型、常见问题。

## 启动提示

对话输入框下方会出现一条中文提示:

```
漫画汉化工作流已就绪
```

- 黄色高亮**闪一下**(约 0.55 秒);
- 停留几秒后**淡出**(opacity 过渡 0.5 秒);
- **不常驻**,消失后不留痕迹;
- 位置在**输入框下方的状态栏右侧**;
- 可在**设置 → 界面选项 → 启动提示弹窗**关掉(默认开启,双端共享)。

## 前提

- 漫画文件夹里已有图片(webp/png/jpg),最好已有 `regions.json`;
- 本地 OCR / GPU 去字需要 `_venv`(torch、manga-ocr、easyocr、iopaint)已存在于工作区;
- 侧边栏面板通过 `/manga-desk/*` 的 Host 接口调用本地脚本。

## 配置

在 `cordis.patch.yml` 的 `config` 中可改:

| 键 | 说明 | 默认 |
|---|---|---|
| `scriptsDir` | 工作流 Python 脚本目录 | `E:/manga_tool` |
| `pythonPath` | 运行脚本的 Python | `E:/_venv/Scripts/python.exe` |
| `lang` | OCR/翻译源语言 | `ja` |
| `engines` | 在线翻译引擎 | `google,mymemory` |
| `proxy` | 翻译代理 | 空 |
| `lama` | 嵌字用 GPU 去字 | `false` |

## 测试方法

### 让 DSH 的 Agent 跑(推荐)

```
用 manga_bench 测一下 <本子目录>
```

### 侧边栏里跑

打开「漫画工作台」→ 粘贴文件夹 → 读取 → 点 OCR / 翻译 / 校对 / 嵌字。

### 自己跑脚本

```sh
python scripts/bench.py <本子目录>          # 只标气泡
python scripts/bench.py <本子目录> --all    # 不过滤
python scripts/measure_detect.py <本子目录> <自动regions.json>
python scripts/measure_precision.py <本子目录> <自动regions.json>
```

前提:本子必须已经人工标好 `regions.json`(作为标准答案),自动标框需要 GPU 与 EasyOCR 模型缓存。

## 限制

- 长段落和花体拟声词的本地 OCR 可能读错或瞎编,需要人工或用 AI 补读;
- GPU LaMa 对密集网点背景会有轻微柔化;
- 自动标框对"不在气泡里的排版文字"和"很小的字"仍会漏检;
- 网页标框仍缺自动标框 / 一键识别 / 重标同步 / 画面缩放;
