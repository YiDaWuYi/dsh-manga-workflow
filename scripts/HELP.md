# 漫画汉化标框工具 · 使用说明

## 一、整体流程

```
1. 标框(自动标框 / 手动框选 / 涂抹)
2. 自动识别(OCR 原文)
3. 检查并修改原文 / 译文(双击框)
4. 校对(嵌字前)—— 检查原文和译文
5. 翻译(在线引擎或交给 AI)
6. 嵌字(embed.bat)
   └── 结束后自动校对输出
```

> 启动页与编辑器顶栏都有 **「设置」**:视觉模型 / API(让 AI 看图用)、界面选项(记住上次路径、DSH 侧边栏)。

### 重新标注之后(重要)

只要你**改动了框的数量/顺序**,旧译文就会和框对不上。这时按顺序重跑一遍:

```
1. 重新标注
2. 自动识别(整本)—— 让 OCR 按新框顺序重生成
3. 翻译(整本)
4. 校对
5. 嵌字
```

也可以直接点工具栏的 **「重标同步」** 按钮,它会自动整本重跑「OCR → 翻译 → 校对」。

## 二、工具栏 · 第一行

| 按钮 | 功能 |
|---|---|
| 上一页 / 下一页 | 翻页,自动保存当前页 |
| 撤销 | 撤销最后一个框(Ctrl+Z) |
| 清空本页 | 清空当前页所有框 |
| 保存 | 写入 regions.json(Ctrl+S) |
| 自动识别(OCR) | 对已有框识别日文/韩文/英文原文 → ocr_text.json |
| 自动标框 | 自动检测文字框(默认只标气泡内文字) |
| 刷新 | 重新适配图片尺寸并重画(F5) |
| 一键识别(标框+OCR) | 先自动标框,再自动识别,一步完成 |
| 重标同步 | 重新标注后整本重跑「OCR → 翻译 → 校对」,避免译文与框错位 |
| 校对(嵌字前) | 检查原文/译文问题,弹窗显示报告 |
| 校对模式下拉 | **原文+译文** = 原文和译文都检查;**只校原文** = 只查 OCR 原文 |
| 翻译 | 用勾选的引擎翻译 OCR 原文 → trans.json |
| 翻译设置 | 选择翻译引擎(可多选)、填写代理 |
| 帮助 | 打开本说明 |
| 范围:当前页/整本 | 上面这些操作只作用于当前页,还是整本 |
| 只标气泡 | 自动标框时只标气泡里的文字(取消勾选则标所有检测到的文字) |

## 二·补充、后台任务与取消

长任务(OCR / 翻译 / 校对 / 自动标框 / 嵌字)都在**后台线程**跑,界面不会卡住:

| 行为 | 说明 |
|---|---|
| 状态栏 | 实时显示子进程输出,例如「翻译中: 进度 3/19 第00000004页」 |
| 互斥 | 同一时间只跑一个任务;重复点按钮会提示「正在执行…」 |
| **取消** | 顶栏「**取消当前任务**」→ 杀掉子进程树(`taskkill /T /F`),状态栏显示「已取消当前任务」 |
| 关窗 | 关闭窗口会自动终止在跑的子进程,不留孤儿进程 |

> 「校对(嵌字前)」以前会**卡住界面最长 180 秒**,现在也走后台,不再冻结;结果仍弹窗展示。

## 四、框的颜色含义

标好的框会按类型显示颜色和标签:

| 颜色 | 左上角标签 | 含义 |
|---|---|---|
| **绿色** | 正文 | 普通对白/叙述 |
| **红色**(线更粗) | 拟声 | 拟声词/艺术字 |

勾选/取消「拟声词(N)」会立即改变框的颜色。

## 六、两种开关的实际效果

新框的**颜色和描边**取自对应的样式组:
- 不勾「拟声词(N)」→ 用**正文样式**;
- 勾选「拟声词(N)」→ 用**拟声词样式**。

框的最终嵌字效果由「拟声词」和「抹除原文」两个开关决定:

| 拟声词 | 抹除原文 | 嵌字效果 | 典型用途 |
|---|---|---|---|
| ☐ | ☑ | 擦原文 + 普通字 | 普通对话框 |
| ☐ | ☐ | 不擦 + 普通字 | 无框正文(旁白、后记) |
| ☑ | ☐ | 不擦 + 粗体 + 外框 | 画面上的拟声词 |
| ☑ | ☑ | 擦原文 + 粗体 + 外框 | 需要擦掉的拟声词 |

## 六·补充、文字样式(正文 / 拟声词)

工具栏第二行下面有**一排紧凑样式按钮**(每组 6 款小图),按钮上直接画出该样式渲染后的样子(所见即所得):

| 正文样式 | 效果 |
| --- | --- |
| 经典 | 黑字 + 白描边(最常用) |
| 极简 | 纯黑无描边 |
| 细边 | 黑字 + 细白边 |
| 加粗 | 粗黑字 + 白描边 |
| 反白 | 白字 + 黑描边(适合深色背景) |
| 投影 | 黑字 + 灰色投影 |

| 拟声词样式 | 效果 |
| --- | --- |
| 漫画 | 黑字 + 白边 + 投影(默认) |
| 反白 | 白字 + 黑边 + 投影 |
| 燃红 | 红字 + 白边 |
| 亮黄 | 黄字 + 黑边 |
| 热橙 | 橙字 + 白边 |
| 冷蓝 | 蓝字 + 白边 |

用法:

1. 点一下样式按钮即选中(高亮显示),之后**新画的框**用这个样式;
2. 想改已有框:选好样式后点右侧「**应用到本页全部框**」,本页所有正文框/拟声框会按当前选择套用;
3. 拟声词样式只用于勾了「拟声词(N)」的框,正文样式用于其余框;
4. 样式定义在 `manga_tool/styles.json`,新增样式改这个文件即可(两端同步)。

> 描边宽度会随字号自动缩放:字号越大,描边越粗,不会出现大字细边。

## 七、自动标框的 `auto` 标记

- 自动标框 / 一键识别产生的框带 `auto` 标记,**不参与嵌字**(只作参考);
- 你**双击改过原文/译文**的框会自动变成"已确认",参与嵌字;
- 手动画的框(框选/涂抹)直接参与嵌字。

所以流程是:**自动标框 → 删掉误检 → 双击确认要用的 → 补框 → 嵌字**。

## 八、翻译设置

| 引擎 | 是否需要机场 |
|---|---|
| Google 免费 | 需要(填代理地址,如 http://127.0.0.1:1080) |
| MyMemory 免费 | 不需要,国内直连 |
| 交给 DSH 里的 AI 翻译 | 不需要(导出请求,由 DSH 会话里的 AI 翻译) |

- 可同时勾选多个在线引擎,并行查询,取最快返回的结果;
- 已有译文的框会自动跳过,不会重复翻译;
- 勾选「交给 AI」后点「翻译」,会导出 `_ai_translate_request.json`,回到 DSH 对 AI 说「处理翻译请求」即可。

## 九、校对

### 嵌字前校对
- **只校原文**:检查 OCR 原文是否齐全、是否有空文本/纯标点。
- **原文+译文**:额外检查译文是否缺失、是否与原文相同(可能没翻译)、是否过长(可能溢出)。
- 拟声词框(勾了「拟声词」)不检查空译文。

### 嵌字后自动校对
嵌字脚本结束后自动运行:
1. 先校原文,再校译文;
2. 检查输出是否缺页;
3. 检查有标框的页是否真的发生了变化(没变说明没嵌上)。

## 十二、视觉引擎(识图)与免费模型

### 为什么需要

想让 AI「看图 / 读图」——检查嵌字效果、读图上的文字、核对气泡位置——**必须先配好视觉引擎**。
本地的日文/韩文 OCR 不需要它,但「让 AI 帮你看图」完全依赖它。

### 在哪里配

启动页的「设置」或「视觉设置」按钮 → 填 **模型名 / API Base / API Key** → 点「测试连接」→ 保存。
写的是 `~/.modlens/config.json` 的 `providers.openai`,网页端的设置改的是**同一个文件**。

### 免费 / 低门槛的视觉模型

| 模型 | API Base | 模型名 | 说明 |
|---|---|---|---|
| 智谱 GLM-4V-Flash | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-flash` | 官方免费 |
| 硅基流动 Qwen2.5-VL | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-VL-7B-Instruct` | 有免费模型,以站内为准 |
| Google Gemini 2.0 Flash | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-2.0-flash` | AI Studio 免费额度 |
| OpenRouter | `https://openrouter.ai/api/v1` | 选带 `:free` 的视觉模型 | 免费模型随时变 |

> 免费额度、模型名与可用性随时可能调整,请以各厂商官网为准。

### 两个测试按钮的区别

| 按钮 | 做什么 | 能证明什么 |
|---|---|---|
| 测试连接 | 发一条最小**文本**请求 | API 地址 / Key / 模型名是否正确,通不通 |
| 测试识图 | 真发一张**绿色三角形**图片,让模型回答形状+颜色 | 模型**是否真的会看图** |

> 纯文本模型(如 `deepseek-chat`)能通过「测试连接」,但会卡在「测试识图」——
> 它要么报错说不支持图片,要么答非所问。所以换完模型**两个都要点一遍**。

### 使用提示

1. 换厂商要**连 API Key 一起换**,只改 API Base 会鉴权失败。
2. 填的模型必须**有视觉能力**,填纯文本模型(如 `deepseek-chat`)会报错。
3. 保存后先点「测试连接」,再在对话里让 AI 读一张图验证。
4. 免费模型通常**有速率限制**,整本批量识图建议用付费或分批进行。
5. 保存后如果当前对话里的识图工具还用旧配置,**重开一次对话**最稳。

桌面端「设置」窗口底部的两个勾选项,以及网页端「设置 → 界面选项」里对应的项:

| 选项 | 范围 | 说明 |
|---|---|---|

## 十四、启动页 · 引擎检测

启动页会自动检测本地引擎是否齐全:

- ✅ 绿色「引擎齐全」= OCR / GPU 去字 / 韩文等全部可用;
- ⚠ 红色「引擎缺失」= 点「引擎帮助」查看缺什么、怎么修;
- 「引擎帮助」里有**复制修复关键词**按钮:复制后打开 DSH 新建工作区,让 AI 自动安装修复。

## 十五、成本预估

「设置」窗口底部有「成本预估」,随单价输入实时更新:

| 项目 | 计算方式 | 参考值(1280×1830 的页) |
|---|---|---|
| **识图**(外接视觉引擎) | 输入 token × 输入单价 + 400 × 输出单价 | 每页 ≈ 2500~3100 输入 tokens |
| **嵌字**(本地 GPU) | 不花钱 | ¥0/页,约 **0.4 秒/页**(本机实测 21 页 8.3 秒) |

- **单价要自己填**(元/百万 tokens),留空按 0 显示 ¥0;单价存 `manga_tool/_cost_cfg.json`;
- 页数/尺寸取**当前本子**的首/中/末 3 页采样,避免只按第一页(可能是短页)低估;
- token 数是按 28px patch 的**估算**,实际以厂商计费口径为准。

## 十六、OCR 兜底(视觉引擎)

本地 OCR 有空/极短的结果时,可以把那几个框**裁图交给视觉引擎重读**(设置 → OCR 兜底):

| 档位 | 触发 | 说明 |
|---|---|---|
| 关闭 | — | 只用本地 OCR |
| **仅空框**(默认) | 识别结果为空 | 安全网,几乎不花钱 |
| 空框 + 极短 | 有效字数 < 阈值(标点不计) | 阈值 1 只补纯标点框;2 会连「ん…」「あ？」一起重读 |
| 全部重读 | 每个有字的框 | 最贵,等于整本视觉校验 |

- **每本上限**(默认 30 框):控制花费,超出部分会提示"已达上限";
- 每框成本 ≈ **¥0.01~0.09**(裁剪图越小越便宜);
- 原 `ocr_text.json` 会先备份为 `.bak`,兜底失败**不覆盖**本地结果;
- **建议用法**:平时保持「仅空框」;发现某本 OCR 明显漏字,临时切「空框 + 极短」并把
  极短阈值设为 2,重跑一次 OCR;补完记得切回「仅空框」,避免后续本子多花钱;
- 跑 OCR 时自动触发,也可以手动:`python manga_tool/ocr_fallback.py <本子> --dry-run --mode short`

## 十七、常见问题

- **看不到框?** 工具启动会自动跳到第一个有框的页;本页真没框时状态栏会提示「本页无标框,按 → 翻页」。
- **自动识别后没有橙色文字?** 检查是否已保存框、是否跑过 OCR、语言是否选对(日/韩/英)。
- **翻译连不上?** Google 需要代理;不开代理可只用 MyMemory 或交给 AI。
- **嵌字后原文还在?** 检查该框是不是取消了「抹除原文」,或带 `auto` 标记。
- **字太大/太小?** 检查「自动字号」是否开启;也可双击框手动调 `size`,或在数据里加 `size_fixed: true` 锁定字号。
- **拟声词没有描边?** 勾选「拟声词(N)」,框会变红并按艺术字处理。
- **每次启动都填上次的文件夹,不想这样?** 设置 → 取消勾选「记住上次路径(本端)」。
- **网页端看不到「漫画工作台」了?** 设置 → 勾回「显示 DSH 侧边栏(双端共享)」,然后在网页刷新一次。
- **AI 看不到图 / 换了模型还是不行?** 设置里先点「测试连接」,再点「测试识图」;都通过后重开一次对话。
- **点了按钮好像没反应?** 看窗口最下面状态栏:会实时显示进度。整本 OCR/翻译本来就要几十秒到几分钟。
- **点错了想中断?** 顶栏点「取消当前任务」即可,子进程会被一起结束。
