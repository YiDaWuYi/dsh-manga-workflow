# 漫画汉化标框工具 · 使用说明

## 〇、使用提示(强烈建议看)

1. **拟声词不要用「GPU 去字(LaMa)」**
   - 拟声词大多压在画面 / 网点 / 线条上,LaMa 修复会把周围画面糊成一片,效果普遍很差;
   - 拟声词建议用 **「译文直盖」**(不动原文直接叠字),或视画面用 **「色块覆盖」**。
2. **翻译请接入 API**
   - 默认会优先使用你配置的 AI 接口(Kimi / DeepSeek 等),质量明显好;
   - 免费渠道(Google / MyMemory)**质量差**,常见错译、音译乱翻、标点错乱,只适合应急。

## 一、整体流程

```
1. 标框(自动标框 / 手动框选 / 涂抹)
2. 自动识别(OCR 原文)
3. 检查并修改原文 / 译文(双击框)
4. 校对(嵌字前)—— 检查原文和译文
5. 翻译(在线引擎或交给 AI)
6. 嵌字(embed.bat)
   └── 结束后自动校对输出
```

> 启动页与编辑器顶栏都有 **「设置」**:视觉模型 / API(让 AI 看图用)、界面选项(记住上次路径、DSH 侧边栏)。

### 重新标注之后(重要)

只要你**改动了框的数量/顺序**,旧译文就会和框对不上。这时按顺序重跑一遍:

```
1. 重新标注
2. 自动识别(整本)—— 让 OCR 按新框顺序重生成
3. 翻译(整本)
4. 校对
5. 嵌字
```

也可以直接点工具栏的 **「重标同步」** 按钮,它会自动整本重跑「OCR → 翻译 → 校对」。

## 二·补充、后台任务与取消

长任务(OCR / 翻译 / 校对 / 自动标框 / 嵌字)都在**后台线程**跑,界面不会卡住:

| 行为 | 说明 |
|---|---|
| 状态栏 | 实时显示子进程输出,例如「翻译中: 进度 3/19 第00000004页」 |
| 互斥 | 同一时间只跑一个任务;重复点按钮会提示「正在执行…」 |
| **取消** | 顶栏「**取消当前任务**」→ 杀掉子进程树(`taskkill /T /F`),状态栏显示「已取消当前任务」 |
| 关窗 | 关闭窗口会自动终止在跑的子进程,不留孤儿进程 |

> 「校对(嵌字前)」以前会**卡住界面最长 180 秒**,现在也走后台,不再冻结;结果仍弹窗展示。

## 六、两种开关的实际效果

新框的**颜色和描边**取自对应的样式组:
- 不勾「拟声词(N)」→ 用**正文样式**;
- 勾选「拟声词(N)」→ 用**拟声词样式**。

框的最终嵌字效果由「拟声词」和「抹除原文」两个开关决定:

| 拟声词 | 抹除原文 | 嵌字效果 | 典型用途 |
|---|---|---|---|
| ☐ | ☑ | 擦原文 + 普通字 | 普通对话框 |
| ☐ | ☐ | 不擦 + 普通字 | 无框正文(旁白、后记) |
| ☑ | ☐ | 不擦 + 粗体 + 外框 | 画面上的拟声词 |
| ☑ | ☑ | 擦原文 + 粗体 + 外框 | 需要擦掉的拟声词 |

## 五·补充、一键识别 = 整本

工具栏的「**一键识别(整本:标框+OCR)**」**始终处理整本**,不受「范围:当前页/整本」影响:

1. 先整本自动标框(只标气泡内文字,`--all` 可标全部文字);
2. 再整本 OCR,逐页写 `ocr_text.json`;
3. 状态栏实时滚动 `进度 x/N` 行,完成后弹窗汇总「整本 N 页,新增框 M 个,OCR K 页」。

> 只想处理**当前页**:用「自动识别(OCR)」或「自动标框」(这两个会跟随「范围」)。
> 任一环节超时会自动终止并提示,不会一直卡住。

## 六·补充、标注模式(1.10 版)

第二行工具栏:**模式 → 类型 → 原文处理 → 字号 → 方向**。

| 项 | 选项 | 说明 |
| --- | --- | --- |
| **模式** | 框选(B) / **自由框选(P)** | 自由框选=按住画一圈(旧称“涂抹”);只处理你画的区域,不会整块抹掉 |
| **类型** | 正文 / 无框正文·拟声词 / 标题 | 绿框 / 红框 / **蓝框(标题嵌字自动居中加粗)** |
| **原文处理** | **译文直盖** / **抹除** / **色块覆盖** | 三种类型都可用 |
| **字号** | 数字 + 自动字号 | 同一组 |
| **方向** | 自动检测 / 竖排 / 横排 | 同一组 |

- **译文直盖**:不动原文,中文直接压上去(适合不想破坏画面时对比效果)。
- **抹除**:会擦掉原文;选中「抹除」后才会出现 **GPU去字** 勾选:
  - 勾上 = 用 GPU(LaMa)修复擦除,质量最好(需要 GPU 环境);
  - 不勾 = 普通抹除(快,复杂背景可能留残影)。
  - **每个框单独记录**,同一页可以有的框 GPU、有的框普通。
- **色块覆盖**:用框边缘的中位色盖住原文。
- **框外标注**:每个框的左上角(外侧)标**类型**,右上角(外侧)标**原文处理**:
  - `直盖`、`覆盖`、`抹除·GPU`、`抹除·普通`
  - 这样一页里有多个标题/不同设置时,一眼能看出每个框是怎么处理的。
- **字体**:样式栏每组右侧有字体下拉(微软雅黑/宋体/黑体/楷体/仿宋/华文仿宋/华文楷体/
  华文琥珀/瘦金体/隶书/幼圆),选完**小图预览立刻同步**;新框和选中框会带上该字体。
- **样式栏可收起**:工具栏右上角「样式 ▾」可折叠/展开,不占画面位置。
- **拟声词最小字号**:自动字号时拟声词不会小于 14 号,避免小字被描边糊成一团看不清。
- **单击框 = 选中**(黄框);选中后改工具栏设置(类型/原文处理/GPU/方向/字号/样式/字体)会
  **立即写回该框**;再点空白处取消选中。旧本子里的框也能这样补标(比如补勾 GPU 去字)。
- 快捷键:`N` 切类型、`E` 切原文处理(直盖→抹除→覆盖)、`V/H` 竖/横、`A` 自动检测。
- 旧本子兼容:旧数据按原字段推断(erase=False→直盖、否则抹除),嵌字效果不变。

## 六·补充2、文字样式(正文 / 拟声 / 标题)


第二行工具栏现在是「模式 → 类型 → 原文处理 → 字号 → 方向」的顺序:

| 项 | 选项 | 说明 |
| --- | --- | --- |
| **模式** | 框选(B) / 涂抹(P) | 前置单选:先选怎么画 |
| **类型** | 正文 / 无框正文·拟声词 / 标题 | 正文=绿框,无框·拟声=红框,标题=**蓝框** |
| **原文处理** | 正文、标题固定「色块覆盖」;无框可切「抹除 / 色块覆盖」 | 色块取框边缘的中位色 |
| **字号** | 数字 + 自动字号(同一组) | 自动字号=按原文字号估算 |
| **方向** | 自动检测 / 竖排 / 横排(同一组) | 取代原来的「自动横竖」勾选 |

- **标题**:嵌字时自动**居中 + 加粗**、自动缩放适配框宽;样式栏新增「标题」一组(5 款)。
- **应用到全部**:把三类样式分别刷到**全书同类型**的框上(正文只刷正文、标题只刷标题);
  和「应用到本页」一样支持 **Ctrl+Z 撤销**。
- 快捷键:`N` 循环切换类型(正文→无框→标题)、`E` 切换抹除/覆盖(无框)、`V/H` 竖/横、`A` 自动检测。
- **旧本子兼容**:以前的框按旧字段自动识别类型,嵌字效果不变(不会因为升级改变旧书观感)。

## 六·补充、文字样式(正文 / 拟声词)

工具栏第二行下面有**一排紧凑样式按钮**(每组 6 款小图),按钮上直接画出该样式渲染后的样子(所见即所得):

| 正文样式 | 效果 |
| --- | --- |
| 经典 | 黑字 + 白描边(最常用) |
| 极简 | 纯黑无描边 |
| 细边 | 黑字 + 细白边 |
| 加粗 | 粗黑字 + 白描边 |
| 反白 | 白字 + 黑描边(适合深色背景) |
| 投影 | 黑字 + 灰色投影 |

| 拟声词样式 | 效果 |
| --- | --- |
| 漫画 | 黑字 + 白边 + 投影(默认) |
| 反白 | 白字 + 黑边 + 投影 |
| 燃红 | 红字 + 白边 |
| 亮黄 | 黄字 + 黑边 |
| 热橙 | 橙字 + 白边 |
| 冷蓝 | 蓝字 + 白边 |

用法:

1. 点一下样式按钮即选中(高亮显示),之后**新画的框**用这个样式;
2. 想改已有框:选好样式后点右侧「**应用到本页全部框**」,本页所有正文框/拟声框会按当前选择套用;
3. 拟声词样式只用于勾了「拟声词(N)」的框,正文样式用于其余框;
4. 样式定义在 `manga_tool/styles.json`,新增样式改这个文件即可(两端同步)。

> 描边宽度会随字号自动缩放:字号越大,描边越粗,不会出现大字细边。

## 七、自动标框的 `auto` 标记

- 自动标框 / 一键识别产生的框带 `auto` 标记,**不参与嵌字**(只作参考);
- 你**双击改过原文/译文**的框会自动变成"已确认",参与嵌字;
- 手动画的框(框选/涂抹)直接参与嵌字。

所以流程是:**自动标框 → 删掉误检 → 双击确认要用的 → 补框 → 嵌字**。

## 八、翻译设置

| 引擎 | 是否需要机场 |
|---|---|
| Google 免费 | 需要(填代理地址,如 http://127.0.0.1:1080) |
| MyMemory 免费 | 不需要,国内直连 |
| 交给 DSH 里的 AI 翻译 | 不需要(导出请求,由 DSH 会话里的 AI 翻译) |

- 可同时勾选多个在线引擎,并行查询,取最快返回的结果;
- 已有译文的框会自动跳过,不会重复翻译;
- 勾选「交给 AI」后点「翻译」,会导出 `_ai_translate_request.json`,回到 DSH 对 AI 说「处理翻译请求」即可。

## 九、校对

### 嵌字前校对
- **只校原文**:检查 OCR 原文是否齐全、是否有空文本/纯标点。
- **原文+译文**:额外检查译文是否缺失、是否与原文相同(可能没翻译)、是否过长(可能溢出)。
- 拟声词框(勾了「拟声词」)不检查空译文。

### 嵌字后自动校对
嵌字脚本结束后自动运行:
1. 先校原文,再校译文;
2. 检查输出是否缺页;
3. 检查有标框的页是否真的发生了变化(没变说明没嵌上)。

## 十二、视觉引擎(识图)与免费模型

### 为什么需要

想让 AI「看图 / 读图」——检查嵌字效果、读图上的文字、核对气泡位置——**必须先配好视觉引擎**。
本地的日文/韩文 OCR 不需要它,但「让 AI 帮你看图」完全依赖它。

### 在哪里配

启动页的「设置」或「视觉设置」按钮 → 填 **模型名 / API Base / API Key** → 点「测试连接」→ 保存。
写的是 `~/.modlens/config.json` 的 `providers.openai`,网页端的设置改的是**同一个文件**。

### 免费 / 低门槛的视觉模型

| 模型 | API Base | 模型名 | 说明 |
|---|---|---|---|
| 智谱 GLM-4V-Flash | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-flash` | 官方免费 |
| 硅基流动 Qwen2.5-VL | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-VL-7B-Instruct` | 有免费模型,以站内为准 |
| Google Gemini 2.0 Flash | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-2.0-flash` | AI Studio 免费额度 |
| OpenRouter | `https://openrouter.ai/api/v1` | 选带 `:free` 的视觉模型 | 免费模型随时变 |

> 免费额度、模型名与可用性随时可能调整,请以各厂商官网为准。

### 两个测试按钮的区别

| 按钮 | 做什么 | 能证明什么 |
|---|---|---|
| 测试连接 | 发一条最小**文本**请求 | API 地址 / Key / 模型名是否正确,通不通 |
| 测试识图 | 真发一张**绿色三角形**图片,让模型回答形状+颜色 | 模型**是否真的会看图** |

> 纯文本模型(如 `deepseek-chat`)能通过「测试连接」,但会卡在「测试识图」——
> 它要么报错说不支持图片,要么答非所问。所以换完模型**两个都要点一遍**。

### 使用提示

1. 换厂商要**连 API Key 一起换**,只改 API Base 会鉴权失败。
2. 填的模型必须**有视觉能力**,填纯文本模型(如 `deepseek-chat`)会报错。
3. 保存后先点「测试连接」,再在对话里让 AI 读一张图验证。
4. 免费模型通常**有速率限制**,整本批量识图建议用付费或分批进行。
5. 保存后如果当前对话里的识图工具还用旧配置,**重开一次对话**最稳。

## 十三、界面选项

桌面端「设置」窗口底部的两个勾选项,以及网页端「设置 → 界面选项」里对应的项:

| 选项 | 范围 | 说明 |
|---|---|---|
| 记住上次路径(本端) | **仅桌面端** | 关闭后启动页不再自动填入上次的文件夹,也不再把本次路径写进 `_last_folder.txt` |
| 显示 DSH 侧边栏(双端共享) | **两端共享** | 关掉后 DSH 左侧边栏不再显示「漫画工作台」入口(网页端刷新 / 重载后生效) |
| 启动提示弹窗(双端共享) | **两端共享** | 输入框**下方状态栏**那条「漫画汉化工作流已就绪」高亮提示;默认开启,关掉后网页端不再出现 |

这三项存在 `~/.manga-workflow/settings.json`,网页端与桌面端改的是**同一个文件**,但两端**只写自己的键**,互不覆盖。
视觉模型的配置在另一个文件:`~/.modlens/config.json`。

## 十四、启动页 · 引擎检测

启动页会自动检测本地引擎是否齐全:

- ✅ 绿色「引擎齐全」= OCR / GPU 去字 / 韩文等全部可用;
- ⚠ 红色「引擎缺失」= 点「引擎帮助」查看缺什么、怎么修;
- 「引擎帮助」里有**复制修复关键词**按钮:复制后打开 DSH 新建工作区,让 AI 自动安装修复。

### 桌面端也能用 DSH 模型翻译(免 Key)

- 插件在 DSH 里运行时会自动开一个**仅本机**的翻译桥(`127.0.0.1`,随机端口 + 令牌);
- 桌面端「翻译设置」勾「交给 DSH 会话翻译」后点「翻译」:
  - **DSH 正在运行** → 直接调用 DSH 模型自动翻译,不导出请求、不花 API 费;
  - **DSH 没运行** → 自动回退为导出请求文件(原来的方式);
- 桥只监听 127.0.0.1、带随机令牌,错误令牌返回 403;DSH 关闭/插件卸载时桥自动关闭并删除配置;
- 网页端无需桥:网页工作台本身就在 DSH 里,直接用模型接口。

### 自动化(不用手动确认)

- **桌面端「全自动(OCR→翻译→校对→嵌字)」按钮**:点一次按「范围」跑完整流程;
  - 翻译引擎按优先级自动选:外接 AI 接口 → 免费渠道;只勾「交给 DSH 会话」时会导出请求(等会话 AI 翻译);
- **网页端「DSH 模型」引擎**:网页端点「翻译」时直接调用 DSH 已配置的模型自动翻译
  (插件 host 用 `ctx.llm.stream`,**不需要任何 API Key**,也不用人工确认);
  - 桌面端是独立进程,拿不到 DSH 模型,所以桌面端的「DSH」选项仍是导出请求;
- 网页设置里引擎选项:DSH 模型(免Key·网页自动)/ 外接 AI 接口 / Google 免费 / MyMemory 免费。

### 自动标框(三种模式)

工具栏「自动标框」后面的下拉:

| 模式 | 行为 |
| --- | --- |
| **全部(自动区分)**(默认) | 标出全部文字,**自动判断类型**:气泡内=正文(绿框,色块覆盖),气泡外=拟声词(红框,抹除) |
| **只标气泡** | 只标气泡内文字,全部按正文处理 |
| **只标拟声词** | 只标气泡外的拟声词,按拟声词处理 |

- 已有标注重叠(<25% 或中心落入)的检测结果会自动跳过,不会重复标框;
- 整本自动标框同样按此规则与类型区分写入。

- 自动标框识别出的**拟声词默认「译文直盖」**(不擦原字);想擦除可在选中框后改成「抹除」;
- 双击框=改原文/译文,双击时不会再误标新框;自由框选里只点一下不会生成零尺寸框。

### 类型/原文处理的「记忆」(软件内)

- 切换「类型」时,会自动**恢复该类型上次用过的**「原文处理」和「GPU」选择:
  - 例如正文用「抹除+GPU」、拟声词用「直盖」,来回切换不用每次重设;
- 记忆只在**本次运行**内有效,退出软件后回到默认(正文=色块覆盖 / 拟声=抹除 / 标题=色块覆盖)。

### 重新翻译与重标后同步

- **重新翻译会覆盖旧译文**(默认开):翻译设置里可关「重新翻译时覆盖已有译文」;
- **「重标同步」**:重新标框后用它一次完成
  1. 对齐 OCR/译文与框(框数变了会自动裁剪/清空该页旧数据,避免错位);
  2. 整本 OCR;
  3. 翻译(按引擎优先级:DSH 模型 / AI 接口 / 免费;会覆盖旧译);
  4. 校对(完成弹窗会显示 问题/提示 条数);
- 底部常驻状态栏显示:第几页/文件名/框数/已译数 + 当前任务进度(工具栏再长也看得到)。

### 翻译引擎优先级(勾选多个时)

1. **高优先级**:「交给 DSH 会话翻译」(导出请求,不花 API 费)/「外接 AI 接口」(自动);
2. **低优先级**:免费渠道(Google / MyMemory),只在没有高优先级可用时兜底;
   - 同时勾选 Google + MyMemory 时,两个渠道并行跑,结果写入 `trans_alt.json` 供对比;
3. 没有全部勾选时,就按你勾选的引擎执行;
4. 「交给 DSH 会话」仅桌面端可用;网页端会自动改用 AI/免费引擎(日志会提示)。

### 翻译引擎设置(双端共享)

- 配置文件:`~/.manga-workflow/trans.json`(桌面端「翻译设置」与网页端「设置 → 文字翻译引擎」改的是同一份);
- **AI 翻译接口**:接口地址 / 模型 / API Key + 「测试接口」按钮(发一句日文验证是否返回中文);
  - 留空 Key = 保持原值不修改;默认会自动复用「视觉引擎」里配好的接口;
- 引擎顺序:**AI 优先**,失败自动回退 Google / MyMemory;
- 免费引擎质量差,仅应急;Google 国内需代理。

## 十四·补充、翻译引擎(重要)

- 默认引擎顺序:**AI(大模型) → Google → MyMemory**;
- **AI 引擎**:自动复用「设置 → 视觉引擎」里配置的 OpenAI 兼容接口(如 Kimi/Moonshot),
  整页批量翻译(每条台词一起给模型,术语/语气更一致);
  - 优点:日译中口语自然、拟声词会译成「扑通/咕叽/嘶啦」这类中文拟声词;
  - 计费:按 token,一页约 1~2 千 token(几分钱),比免费引擎质量高一个量级;
  - 失败自动回落到免费引擎。
- 想改接口/模型:在书文件夹放 `_trans_ai.json`
  (字段 `baseUrl`/`apiKey`/`model`),或用「翻译设置」里的 AI 项。

## 十五、成本预估

「设置」窗口底部有「成本预估」,随单价输入实时更新:

| 项目 | 计算方式 | 参考值(1280×1830 的页) |
|---|---|---|
| **识图**(外接视觉引擎) | 输入 token × 输入单价 + 400 × 输出单价 | 每页 ≈ 2500~3100 输入 tokens |
| **嵌字**(本地 GPU) | 不花钱 | ¥0/页,约 **0.4 秒/页**(本机实测 21 页 8.3 秒) |

- **单价要自己填**(元/百万 tokens),留空按 0 显示 ¥0;单价存 `manga_tool/_cost_cfg.json`;
- 页数/尺寸取**当前本子**的首/中/末 3 页采样,避免只按第一页(可能是短页)低估;
- token 数是按 28px patch 的**估算**,实际以厂商计费口径为准。

## 十六、OCR 兜底(视觉引擎)

本地 OCR 有空/极短的结果时,可以把那几个框**裁图交给视觉引擎重读**(设置 → OCR 兜底):

| 档位 | 触发 | 说明 |
|---|---|---|
| 关闭 | — | 只用本地 OCR |
| **仅空框**(默认) | 识别结果为空 | 安全网,几乎不花钱 |
| 空框 + 极短 | 有效字数 < 阈值(标点不计) | 阈值 1 只补纯标点框;2 会连「ん…」「あ？」一起重读 |
| 全部重读 | 每个有字的框 | 最贵,等于整本视觉校验 |

- **每本上限**(默认 30 框):控制花费,超出部分会提示"已达上限";
- 每框成本 ≈ **¥0.01~0.09**(裁剪图越小越便宜);
- 原 `ocr_text.json` 会先备份为 `.bak`,兜底失败**不覆盖**本地结果;
- **建议用法**:平时保持「仅空框」;发现某本 OCR 明显漏字,临时切「空框 + 极短」并把
  极短阈值设为 2,重跑一次 OCR;补完记得切回「仅空框」,避免后续本子多花钱;
- 跑 OCR 时自动触发,也可以手动:`python manga_tool/ocr_fallback.py <本子> --dry-run --mode short`

## 十七、常见问题

- **看不到框?** 工具启动会自动跳到第一个有框的页;本页真没框时状态栏会提示「本页无标框,按 → 翻页」。
- **自动识别后没有橙色文字?** 检查是否已保存框、是否跑过 OCR、语言是否选对(日/韩/英)。
- **翻译连不上?** Google 需要代理;不开代理可只用 MyMemory 或交给 AI。
- **嵌字后原文还在?** 检查该框是不是取消了「抹除原文」,或带 `auto` 标记。
- **字太大/太小?** 检查「自动字号」是否开启;也可双击框手动调 `size`,或在数据里加 `size_fixed: true` 锁定字号。
- **拟声词没有描边?** 勾选「拟声词(N)」,框会变红并按艺术字处理。
- **每次启动都填上次的文件夹,不想这样?** 设置 → 取消勾选「记住上次路径(本端)」。
- **网页端看不到「漫画工作台」了?** 设置 → 勾回「显示 DSH 侧边栏(双端共享)」,然后在网页刷新一次。
- **AI 看不到图 / 换了模型还是不行?** 设置里先点「测试连接」,再点「测试识图」;都通过后重开一次对话。
- **点了按钮好像没反应?** 看窗口最下面状态栏:会实时显示进度。整本 OCR/翻译本来就要几十秒到几分钟。
- **点错了想中断?** 顶栏点「取消当前任务」即可,子进程会被一起结束。
