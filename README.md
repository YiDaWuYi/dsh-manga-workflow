DeepSeek Harness 的漫画汉化工作流插件:本地 OCR(日/韩/英)、GPU 去字(LaMa)、中文嵌字,
**标注体系(正文/拟声词/标题、原文处理、按框 GPU)**、**翻译引擎优先级**、**全自动流程**,
外加**启动提示栏**和**自动标框基准测试**。

## 提供的工具

| 工具 | 作用 |
|---|---|
| `manga_ocr` | 对已标框的漫画文件夹跑本地 OCR,生成 `ocr_text.json` |
| `manga_embed` | 按 `trans.json` 擦原文 + 写中文,可选 GPU LaMa 去字或预览 |
| `manga_status` | 汇总页数、框数、翻译进度 |
| `manga_bench` | 把已有 `regions.json` 当标准答案,测自动标框的召回/精确/噪声率 |

## 侧边栏:漫画工作台

插件启用后,左侧边栏多出 **🎨 漫画工作台** 入口,点开是一个工作台面板:

| 启动页 | 标题、路径输入、「浏览…」系统对话框、引擎检测、视觉引擎状态、页脚声明 |
| 文件夹输入 | 粘贴路径 / 点「浏览…」选目录 / 记住上次路径 |
| 状态 | 页数、框数、已翻译数(底部常驻:第几页/文件名/框数/已译数) |
| 流程按钮 | OCR / 翻译 / 校对 / 嵌字(**异步任务,日志实时滚动**) |
| 页码导航 | ◀ / ▶ 翻页 + 保存(Ctrl+S) |
| 网页标框 | 框选 / **自由框选**;类型(正文/无框正文·拟声词/标题);原文处理(译文直盖/抹除/色块覆盖)+ 按框 GPU;方向三选(自动/竖/横);字号+自动字号;单击选中后改设置实时写回;框外标注;右键删框;双击改字;撤销 |
| 文字样式 | 正文 / 拟声 / 标题 三组预设 + **字体下拉 + 实时预览**;应用到本页 / 应用到全部;「样式 ▾」可收起 |
| 翻译设置 | 设置页「文字翻译引擎」:DSH 模型 / 外接 AI 接口 / Google / MyMemory(双端共享,网页端可直接用 DSH 模型自动翻译) |
| 设置 / 帮助 | 顶部「设置」「帮助」,也可从启动页进入 |
| 日志 | 脚本运行输出(轮询任务进度) |

> 网页版仍缺:自动标框、一键识别、同步(配对)、画面缩放、全自动按钮。这些用桌面版 `mark.bat`;
> 启动页也能一键「启动桌面版」并自动带上当前文件夹。

**长任务**:网页端是后端异步任务 + 前端轮询日志;桌面端是后台线程 + 状态栏流式进度,
并可用顶栏「取消当前任务」杀进程树(网页端暂不能中断)。

## v1.10 桌面端大改版(重点)

桌面版 (`manga_tool/mark_tool.py`,程序内「帮助」有完整说明):

### 标注体系

| 项目 | 说明 |
|---|---|
| **模式** | 框选(B) / 自由框选(P,原「涂抹」) |
| **类型** | 正文(绿框) / 无框正文·拟声词(红虚线) / 标题(蓝框、嵌字居中加粗) |
| **原文处理** | 译文直盖 / 抹除 / 色块覆盖;选「抹除」时出现**按框 GPU 去字**勾选 |
| **框外标注** | 左上=类型,右上=原文处理(`直盖`/`覆盖`/`抹除·GPU`/`抹除·普通`) |
| **点选编辑** | 单击框=选中(黄框),之后改类型/处理/GPU/方向/字号/样式会**立即写回该框** |
| **方向** | 自动检测 / 竖排 / 横排 |
| **字号** | 手动字号 + 自动字号(拟声词自动放大、正文超框自动缩小) |

### 样式 / 工具栏 / 快捷键

- 三组样式(正文 / 拟声 / 标题)+ **字体下拉**(宋体/黑体/楷体/仿宋/华文系列/瘦金体/隶书/幼圆)+ 实时预览;
- 「应用到本页」「应用到全部(按类型刷全书)」;「样式 ▾」可收起,再展开回到原位;
- 工具栏重排:「校对」移到「翻译」后;翻译设置/设置/帮助收进「更多 ▾」;「取消当前任务」独立按钮;
- **底部常驻状态栏**:第几页/文件名/框数/已译数 + 当前任务进度;
- 快捷键:`B/P` 模式、`1/2/3` 类型、`E` 原文处理循环、`G` GPU(仅抹除)、`T` 翻译、`O` 识别、
  `Ctrl+Z` 撤销、`Ctrl+S` 保存、`←/→` 翻页、`F5` 刷新(输入框内不误触);
- **软件内记忆**:每种类型各自记住上次的「原文处理/GPU」,切换类型自动恢复(退出软件重置)。

### 自动标框(三模式)

| 模式 | 行为 |
|---|---|
| **全部(自动区分)**(默认) | 标全部文字,气泡内=正文 / 气泡外=拟声词(结合气泡判定 + 墨量特征) |
| 只标气泡 | 只标气泡内文字(全部按正文) |
| 只标拟声词 | 只标气泡外文字(按拟声词) |

- 与已有标注重叠(<25% 或中心落入)的检测结果**自动跳过**,不会重复标框;
- 识别出的**拟声词默认「译文直盖」**;整本自动标框同样适用。

### 翻译 / 自动化

- **翻译引擎优先级**:DSH 模型 / 外接 AI 接口(高)→ 免费渠道(低,仅兜底);
  同时勾选多个免费渠道会并行翻译并写 `trans_alt.json` 供对比;
- **重新翻译覆盖旧译文**:默认开(翻译设置里可关);
- **同步**:只把已标注框的「原文 ↔ 译文」按当前框顺序重新配对(不 OCR、不翻译;框数变化自动裁剪/补空并提示被裁条数);
- **全自动按钮**:OCR → 翻译 → 校对 → 嵌字,一次点完;
- **DSH 本机桥**:DSH 运行时自动开 `127.0.0.1` 随机端口+令牌的小接口,
  桌面端勾「交给 DSH 会话翻译」即可**免 API Key 直接调用 DSH 模型**;
  DSH 没运行时自动回退为「导出请求」方式。

## OCR 兜底(视觉引擎)

本地 OCR 识别不可靠时,**自动把框内图裁下来交给视觉引擎重读**,写回 `ocr_text.json`
(原文件先备份成 `ocr_text.json.bak`)。

| 阈值档位 | 触发条件 | 典型候选数(实测 210 框的本子) |
|---|---|---|
| **关闭** | 不兜底 | 0 |
| **仅空框**(默认) | OCR 结果完全为空 | 0(安全网) |
| **空框 + 极短** | 有效字数 < 阈值(标点/省略号不计) | 阈值 1 → 7 框;阈值 2 → 15 框 |
| **全部重读** | 每个有字的框 | 210 框(受上限约束) |

- **短句自动兜底**(默认开):有效字数 **≤5(不含标点)** 的框也送视觉引擎重读,可在设置取消;
- **已兜底标记**:处理过的框记在书的 `ocr_fallback_done.json`,重复跑 OCR 不会重复花钱(`--force` 可强制重跑);
- 兜底改了原文后**自动做一次「同步」**(原文↔译文重新配对);
- **每本上限**(默认 30 框)控制花费:每框约 **¥0.01~0.09**(取决于裁剪图大小与模型);
- 只在对该本子跑 OCR 时触发一次;兜底失败**不影响**已成功的本地 OCR 结果;
- 配置存 `manga_tool/_ocr_cfg.json`,网页端与桌面端**改的是同一个文件**;
- 命令行:`python manga_tool/ocr_fallback.py <本子> --dry-run --mode short` 可先看候选。

## 运行环境(自动探测 + 一键安装)

插件**自带工具链**(OCR / 翻译 / 校对 / 嵌字 / 自动标框脚本都在插件 `scripts/` 里),
安装后不需要再下载 `manga_tool`。

- **Python 自动探测**:按 `插件配置 → 环境变量 DSH_MANGA_PYTHON → 插件内置 _venv →
  相邻 _venv → 系统 PATH` 顺序找 Python 3.9+,设置页会显示用的是哪个;
- **设置页 → 运行环境**:三档依赖状态 + 一键安装
  - 基础(Pillow / numpy / OpenCV / requests,约 100MB)—— 标框、翻译、嵌字必需
  - 本地 OCR(torch / manga-ocr / easyocr,约 2GB)—— 要本地 OCR 才装
  - GPU 去字(iopaint,可选)—— 想用 LaMa 擦字才装
- **安装前必须先选安装位置**(设置页「运行环境 → 安装位置」):
  - 点「选择目录…」挑一个目录,或点建议的 `D:\dsh-manga-env` 之类;
  - **禁止选 C 盘**(C 盘会被前端与后端同时拦下,避免把几个 GB 的模型/依赖塞进系统盘);
  - 依赖与服务环境全部装到该目录,安装日志实时滚动;
- 想用自己已有的环境:在插件配置里写 `pythonPath` / `scriptsDir` 即可优先使用。

## 视觉引擎(识图)

> **让 AI「看图 / 读图」必须先配好视觉引擎。** 本地 OCR 不需要它,但检查嵌字效果、
> 读图上的文字、核对气泡位置完全依赖它。

启动页会显示当前视觉引擎状态(✅ 已配置 / ⚠️ 未配置)并提供「去设置」入口;
工作台顶部、网页帮助页与桌面版 `HELP.md` 都写明了用法与免费方案。

### 免费 / 低门槛的视觉模型

| 模型 | API Base | 模型名 | 说明 |
|---|---|---|---|
| 智谱 GLM-4V-Flash | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-flash` | 官方免费 |
| 硅基流动 Qwen2.5-VL | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-VL-7B-Instruct` | 有免费模型,以站内为准 |
| Google Gemini 2.0 Flash | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-2.0-flash` | AI Studio 免费额度 |
| OpenRouter | `https://openrouter.ai/api/v1` | 选带 `:free` 的视觉模型 | 免费模型随时变 |

免费额度与可用性随时可能调整,以各厂商官网为准。

### 使用提示

1. 换厂商要**连 API Key 一起换**,只改 API Base 会鉴权失败。
2. 模型必须**有视觉能力**,填纯文本模型(如 `deepseek-chat`)会报错。
3. 保存后先点「测试连接」,再在对话里让 AI 读一张图验证。
4. 免费模型通常有速率限制,整本批量识图建议付费或分批。
5. 保存后若对话里的识图工具仍用旧配置,**重开一次对话**最稳。

## 设置(视觉模型 / API)

网页端启动页与工作台顶部、桌面版主页与编辑器顶栏都有「设置」按钮。

**控制的是 DSH 识图用的视觉模型(modlens)**,写入 `~/.modlens/config.json` 的 `providers.openai`,
所以改完就等于替换掉当前在用的那一家 API(比如换成别家、或把月之暗面换掉)。

- **字段**:模型名、API Base、API Key(OpenAI 兼容协议)
- **快速预设**:月之暗面 / 通义千问VL / 智谱 GLM-4V / OpenAI,点一下自动填 Base + 常用模型名
- **存储**:两端共用 `~/.modlens/config.json`,桌面版与网页版改的是同一个文件
- **测试连接**:向 `{API Base}/chat/completions` 发一次最小文本请求(`max_tokens: 8`),只看 API 通不通
- **测试识图**:真发一张**程序生成的绿色三角形图**,让模型回答形状+颜色 —— 只有它答对才算「会看图」;
  纯文本模型即使 API 通,这一步也会判为「没看懂图」
- **API Key**:保存后只显示打码形式(`sk-i****D7gM`);留空表示不修改,「清空 Key」才会删除
- **保留字段**:写回时会保留 modlens 原有的 `structuredOutput`、`extraBody` 以及其它 provider

示例 `~/.modlens/config.json`:

```json
{
  "providers": {
    "openai": {
      "baseUrl": "https://api.moonshot.cn/v1",
      "apiKey": "sk-...",
      "model": "kimi-k3",
      "structuredOutput": true,
      "extraBody": { "thinking": { "type": "disabled" } }
    }
  }
}
```

## 前提

- 漫画文件夹里已有 `regions.json`(用工作区的 `mark.bat` 标框得到);
- 本地 OCR / GPU 去字需要 `_venv`(torch、manga-ocr、easyocr、iopaint)已存在于工作区;
- 缺失时工作区标框工具的启动页会提示,并可复制修复关键词交给 AI 安装。

## 限制

- 长段落和花体拟声词的本地 OCR 可能读错或瞎编,需要人工或用 AI 补读;
- GPU LaMa 对密集网点背景会有轻微柔化;
- 自动标框对"不在气泡里的排版文字"和"很小的字"仍会漏检;
- 自动区分的类型不是 100% 准确:纯浅笔画、贴着气泡边的拟声词仍可能被判成正文,
  选中后按 `2` 改成拟声词即可(v1.10 已加入墨量判别,准确率比旧版更好);
- 框画得比气泡大时,文字仍可能压到气泡外 —— 这是框的几何问题,建议标框贴合气泡。
